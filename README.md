# Test Atölyesi

Çevrimdışı çalışan test çözme uygulaması (PWA).

- Uygulama: https://bahadrax.github.io/test-atolyesi/
- Telefonda tarayıcı menüsünden "Ana ekrana ekle" ile kurulur.
- Google ile giriş: veriler kullanıcının kendi Drive klasöründe ("Test Atölyesi") tutulur; uygulama yalnız bu klasörü görür (drive.file).
- Bu depoda kitap içeriği yoktur.
